    About the cabinet

    Nine small amusements, each after a tale by Edgar Allan Poe, kept in a cabinet of curiosities. Open a drawer and the game is yours for a few minutes; your best result is written on the tag and kept in this browser only.

    Every specimen was built on a different technology, so no two drawers behave alike:

    Web Audio synthesis · three.js · Matter.js physics · raymarched WebGL2 SDFs · GPU particles · a cipher engine on procedural parchment · pure CSS 3D · engraved SVG · a Rust/WebAssembly simulation

    The launcher itself is SVG joinery, CSS light and one small canvas of dust.
